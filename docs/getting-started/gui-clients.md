# 图形客户端

不想天天敲命令，可以用带界面的程序。它们多半内置或调用 Mihomo，界面负责订阅、切节点、开系统代理或 TUN。

列表以官方为准（软件会换代）：  
https://wiki.metacubex.one/startup/client/client/

---

## 壳和芯

界面是壳：按钮、订阅、托盘。  
真正做代理、读 YAML 的是核心进程。

界面打不开、订阅导入失败，多半找客户端项目。  
规则不生效、协议报错、内核崩，先看日志是不是核心的问题，再对照官方 wiki。

有的客户端能换核心版本；升级界面不等于核心一定是最新。

---

## 界面里一般要填什么

和手写配置是同一套信息：订阅链接或单个节点参数、是否开系统代理、是否开 TUN、规则模式还是全局。

若客户端支持「打开配置目录 / 编辑配置」，改的仍是核心在读的那份（或它生成的等价物）。

---

## 和命令行别抢

同一台机器上，两个程序别抢同一个 `mixed-port`，系统代理也只能指向一个端口，TUN 更不宜叠多个。  
要么客户端托管核心，要么自己 `mihomo -d ...`，选一条路。

---

## 面板

有的客户端自带界面；也可以让核心开 `external-controller`，用浏览器开 Metacubexd、Yacd 等（见安装章）。  
API 绑 `127.0.0.1` 更安全；对局域网开放务必设 `secret`。
