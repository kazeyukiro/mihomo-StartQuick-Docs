# 快速开始

概念篇看完了，这边开始动手。

官方入口在这里：https://wiki.metacubex.one/startup/  
下面用更啰嗦、更适合零基础的说法，把「下载 → 跑起来 → 写最小配置」串一遍。

## 学习路线

```text
选对二进制并下载
   ↓
准备一份最小配置
   ↓
前台跑一次，确认能起来
   ↓
（可选）做成开机服务
   ↓
（可选）接上 Web 面板
```

推荐按侧边栏顺序看：

1. [怎么下载、选哪个文件](./install)
2. [第一份配置文件](./first-config)
3. [添加第一个代理并验证](./first-proxy)

:::tip
示例里的服务器地址、密码都是假的，只为说明结构。  
真实节点参数请换成你自己有权使用的。
:::
