# 快速开始

概念篇看完了，这边动手。

官方入口：https://wiki.metacubex.one/startup/

## 路线

```text
选对二进制并下载
   ↓
最小配置，前台跑通
   ↓
换上真实节点并验证
   ↓
（建议）基础分流：国内直连 / 名单代理
   ↓
（可选）图形客户端或 Web 面板
   ↓
（可选）systemd 长期跑
```

1. [怎么下载、选哪个文件](./install)
2. [第一份配置文件](./first-config)
3. [添加第一个代理并验证](./first-proxy)
4. [基础分流](./basic-routing)
5. [图形客户端](./gui-clients)

示例里的服务器地址、密码都是假的，换成你有权使用的参数。
