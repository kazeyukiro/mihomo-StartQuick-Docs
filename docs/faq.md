# 常见问题

## Mihomo 是客户端吗？

它是代理**核心**。  
带界面的程序可以调用它；你也可以直接跑二进制。  
本机跑时多半当本地核心，服务器上也可以当入站服务端。

## 节点和代理有啥区别？

配置里 `proxies` 每一项就是一个节点（一组连出去的参数）。  
「代理」口头上常混着用，指转发这件事或指那个节点都行，看上下文。

## 配置为什么这么长？

因为要同时描述：流量从哪进、DNS、规则、组、节点、怎么出站。  
分开看每一块，比盯着一整份 YAML 好懂。  
完全零基础可以从「小小白白话文」看起。

## 从哪读起？

- 概念不清楚 → 小小白白话文  
- 已经知道代理 / 规则 → 快速开始  
- 查字段 → 配置参考 + 官方 wiki
