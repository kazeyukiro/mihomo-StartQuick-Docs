# 常见问题

## Mihomo 是客户端吗？

严格来说，Mihomo 更适合被理解为一个网络代理核心。

各种图形客户端可以调用 Mihomo，让用户更方便地管理配置和控制流量。

跑在你本机上时，它主要扮演「本地代理核心」的角色；跑在服务器上时，也可以当代理服务端用。

## 节点和代理有什么区别？

简单理解：

> 节点是一组具体的代理服务器配置；代理是「帮你转发请求」这件事本身。

日常说话里大家经常混着说，问题不大。看配置的时候，`proxies` 下面的每一项就是一个节点。

## 为什么配置文件这么复杂？

因为 Mihomo 同时处理：

- 流量进入（入站）
- DNS
- 规则
- 代理组
- 节点
- 流量输出

把这些东西拆开理解，就不会觉得配置文件那么神秘。

建议先从「🌱 小小白白话文」把概念过一遍。
