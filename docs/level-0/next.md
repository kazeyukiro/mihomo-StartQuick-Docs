# 看完这些概念之后，接下来该干什么？

如果你把前面几章都大致看懂了，恭喜，你已经具备了「能看懂大部分配置」的基础。

建议的下一步：

1. **去官方 wiki 看一遍配置示例**  
   https://wiki.metacubex.one/  
   先看 General、DNS、Proxies、Proxy Groups、Rules 这几章。  
   现在再看，很多字段你至少知道它在解决什么问题。

2. **找一份最简单的配置，自己跑起来**  
   不要一上来就抄那种几百行的「完美配置」。  
   先用最基础的 `mixed-port` + 几个节点 + 几条规则，确认能通。  
   仓库里的「快速开始」就是干这个的。

3. **再慢慢加东西**  
   先加 proxy-groups，再加 dns，再考虑 rule-set、TUN、fake-ip……  
   每加一样，就弄清楚它解决的是什么痛点。

4. **出问题的时候，先看日志**  
   `log-level` 先设成 `info` 或 `debug`，看 Mihomo 到底在抱怨什么。

---

## 最后再啰嗦一句

Mihomo 本身只是工具。  
它能帮你把流量管得井井有条，但它解决不了「节点质量差」「协议被针对」「你自己配置写错」这些问题。

把概念搞清楚，比收藏一百份「终极配置」有用得多。

有问题就去官方 wiki 或者相关社区问，记得把完整配置和日志贴出来（敏感信息打码）。

加油。
