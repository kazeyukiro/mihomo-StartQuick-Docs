# Mihomo 小小白白话文 · 前言

这篇东西是写给谁的？

写给**第一次听到 Mihomo（或者以前叫 Clash Meta）**、看到配置文件就头晕、分不清 proxies / proxy-groups / rules / dns 是什么的人。

如果你已经会自己写配置、会调规则、会玩 TUN、会玩 dialer-proxy，那这篇对你没用，直接关掉就行。

---

## 这篇不是什么

不是官方文档的精简版。  
不是「一键配置大全」。  
不是教你怎么自建节点、怎么买机场、怎么挑线路。

它只做一件事：

> **说人话，让你理解 Mihomo。**

---

## 为什么需要单独写一篇？

官方 wiki（ https://wiki.metacubex.one/ ）写得很全，但默认你已经知道：

- 什么是代理
- 什么是节点
- 什么是规则
- 什么是 DNS
- 为什么要有 proxy-groups

零基础的人打开 wiki，第一反应通常是：

> 这ᵀᴹ都是什么鬼？

而网上的教程又经常一上来就甩一堆完整配置，中间夹杂各种「建议开启 fake-ip」「推荐用 rule-set」之类的话，新手根本不知道这些东西在解决什么问题。

所以这篇就从最基础的「它到底在干什么」开始讲。

---

## 郑重声明

1. 技术一般，文章肯定有漏、有错。发现了请温柔提醒。
2. 本文不负责教你怎么翻墙、怎么选节点、怎么规避风险。任何使用后果自负。
3. 语言会比较啰嗦。因为目标是零基础，宁可多说两句，也不假设你已经懂了。
